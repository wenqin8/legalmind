# M4独立法律复核资料

当前状态：未安排、未完成。用户选择先交付课程MVP，原法律验收门槛保留。本资料仅准备复核入口，没有专家签名或通过结论；无需为工程交付运行付费模型。

## 先复核标注

1. 复核人须未参与本项目实现和出题，填写[空白模板](m4-legal-review-template.json)的身份、资质、独立性及日期。
2. 阅读[未执行v12](../../backend/data/evaluation/m4-once-v12/README.md)中的queries/scenarios、rubric和manifest，并核对`eval-rag-v2-209`本地核验快照的版本、适用日期、必要条件、例外和资料覆盖。
3. 逐题填写24条记录，确认行为及rubric、主题独立性与来源；标为pending或null的字段不计通过。尤其检查跨条文关系、预约/本约完整性及缺失被引全文。
4. 如需纠正标签，另存复核稿和理由，保留原冻结文件。正式执行前将确认后的标签另建新版本并重新冻结，保留v12；不要直接覆盖旧rubric或manifest。

## 后复核实际答案

独立标注、实现冻结及最终调用预算明确后，才首次执行新包。失败或部分执行也消耗未见状态，不重置receipt，不拼接最佳答案。模板中的`raw_answer_report`指向完整原报告，逐句确认原文支持、条件/例外、适用性及无法回答的边界，再填写faithfulness/applicability；仅结构校验或模型自审不等于通过。

已观察数据只用于开发：v6首次与后续回归分别保留，Run11仍是不完整失败；不能用旧回答填入本模板充当v12首次成绩。模板不直接作为门槛CLI输入；正式语义审查采用[验证方法](../acceptance/rag-v2-offline.md)规定的review格式及对应原始答案哈希，独立标注另存证明。整个过程不修改首次原报告。
