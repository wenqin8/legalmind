# M4人工复核：资料与标准

2026-10-01。建议先复核24题的题目及判定依据，再复核未来实际生成的答案。v12尚未提交模型，所以现在没有该套题的模型答案可审。本次只准备资料，不执行付费模型，不改原冻结文件。

由用户开展人工复核，复核记录填写真实身份、法律资质/经验、是否参与实现或出题和日期。项目负责人复核与独立法律专家复核分别记录；用户身份或勾选通过本身不能证明专业资质、独立性，也不自动满足冻结包的expert_annotation_required。若这些条件尚未确认，独立专家项继续保留未完成。

## 第一阶段：24题题目与金标准

| 检查项 | 通过条件 | 不通过或待核的典型情况 |
| --- | --- | --- |
| 题意与分支 | 问题明确；区分一般规则、个案判断及请求类型；gold只要求回答所问分支。 | 要求回答未问的另一请求；题意无法确定。 |
| 来源真实性 | 能定位官方原文；法规名、条号、版本与快照一致。 | 条文错配、不同法规同号混用、用合成案例证明法律结论。 |
| 时间适用 | 正确区分公布、生效、核验和状态截止；根据事件日与过渡规则判定，不能把核验日当生效日。 | 忽略旧法、尚未终审/再审等过渡前提；把本地快照称实时现行法。 |
| 必要条件与例外 | 写明所问分支的前提、且/或者关系、例外、主体和法律后果；实质条件齐全即可，不机械要求重复条号。 | 删除决定结论的条件；把“可以”写成“必须”；因未复写编号否定已完整表达的条件。 |
| 预期answer | 当前资料足以支持所问规则，可受限回答；一般规则不因没有个案事实而过度追问。 | 要求依靠未收录全文或推测才能给出确定结论；可回答题被错标资料不足。 |
| 预期clarify | 确有会改变判断的必要事实缺失，且原文支持要求该事实；列明最少需要补问什么。 | 任意索取个人信息；把缺地方文件伪装成缺用户事实。 |
| 预期insufficient | 指明库中缺哪类资料、地区/年份或被引全文，以及不能判断的部分；已能支持的部分可受限说明。 | 编造地方金额、引用或全文；资料缺失却仍给出确定结果。 |
| 新题独立性 | 记录与已观察题是否实质重复，不能只凭精确文本不同认定独立；如需比较，可查[旧开发集](../../backend/data/evaluation/rag-v1/README.md)和[已观察v6](../../backend/data/evaluation/m4-once-v6/README.md)。 | 仅换人名、措辞或日期复述已反复调优的争点；未经核实仍称第三方盲测。 |

每题填写“通过／需修改／待核”、理由、官方链接及具体条款位置。需修改时另存纠正稿，保留原queries/rubric/manifest；正式执行前使用确认后的输入另建版本。允许每批6题，先婚姻家庭，再劳动争议、交通事故和合同纠纷。24题全部记录后才能认定标注复核完成；有待核不计通过。

## 第二阶段：实际答案语义复核

仅在新包正式首次执行并保存完整原报告后开展。对每条实际返回的实质法律答案逐句核对：

- `faithfulness`（忠实于证据）：权利、义务、例外、金额、程序及法律后果都有本轮原文支持；引用确实对应结论；无编造来源或“引用正确、结论无依据”。
- `applicability`（适用正确）：来源适用于本题事实、日期、主体、请求及程序阶段；所问分支的必要前提和例外完整，配套背景不扩大为新请求。
- 同时核对缺事实/资料不足的判断是否准确、是否确实解决所问问题、是否把不确定表述藏在免责声明后面。主要结论有无依据错误、关键前提遗漏或适用性存疑时，不计通过。

逐项记录pass/fail及具体句子、依据、理由；拿不准时标待核，不使用pass。空白、代理初评、模型自审与结构检查不能代替人的语义结论。记录绑定原始答案文件SHA-256；旧开发报告使用“场景ID:轮次”键。储备集的标注模板不是开发集门槛脚本的直接输入；不同报告格式须对应处理，不能改名混用。

## 完成与通过标准

- **人工标注完成**：24题逐题有明确结论和依据，修改项处理完毕，待核为0；专业资质与独立性如实记录，符合时才标为独立专家标注完成。
- **v12冻结门槛**：全部24题执行；行为匹配至少85%，即至少21/24；服务失败0、硬性结构失败0；另需逐条语义复核及独立法律标注。21题行为匹配不自动证明法律结论正确。
- **硬性检查**：来源真实性与已知引用、逐字引文、模型不得新增链接、版本区间、字段来源以及适用场景的冲突保留/确认。未经输出的字段不强行要求；不能通过删题或遗漏失败记录避开检查。
- **证据有效**：使用一致的实现、语料和输入；完整原报告保留，失败、未执行及原分母不删除。首次失败或部分执行也永久消耗该包未见状态，后续只称开发回归。
- **结论分开**：课程工程通过、法律质量通过、独立专家复核完成和安全审计通过分别记录。原开发集还要求Top5直接命中≥90%、资料不足安全处理100%及四类更正确认等，不用它的36场景/52轮脚本直接判定新24题包。

可按以下格式回复，或填写人工表的副本：

```text
复核人／资质或经验／是否参与实现或出题／日期：
题号：RESERVE-marriage_family-01
结论：通过／需修改／待核
预期行为：answer／clarify／insufficient
必须保留的条件、例外或补问项：
发现的问题与建议修改：
官方证据链接和条款位置：
```

只需提交你的逐题判断和依据；不需要自行改代码、运行付费模型或编辑原冻结标签。后续由代理整理复核记录、处理修改及报告哈希，保留你的原始结论。
