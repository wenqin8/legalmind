- QA补充、更正、确认续接原任务，四领域日期修改先显示冲突，再确认新值；显式新任务仍可切换。字段消息出处与Redis过期、互斥、保存补偿保持原设计。

- 每个法律段落依次进行来源身份检查、逐句支持检查、独立条件反例检查，再发送。后两项分别判断是否存在直接原文，以及是否遗漏前提、例外或改变逻辑；不是同一答案重复投票。支持片段可忽略空白定位，用户可见引文仍匹配原文。失败段落最多修订一次，二次检查仍失败则停止，不入历史。全部调用共享原总超时。
- 增加交通解释二全部12条官方原文、出处、版本、哈希和过渡规则。施行前事故需要核实终审状态；已终审再审不套新解释。原文核对日期2026-09-24，状态截止仍按官方施行公告2026-06-30记录，不宣称穷尽后续修改或整个领域完整覆盖。

4条可回答请求仍返回424，未保存失败内容：

因此下一步应改进审核对已验证前段条件的上下文继承、减少泛化扩写和过度保守拒绝；不能通过删除这些失败或放宽无依据结论检查提高成绩。最终来源Recall仍只有53.57%，召回完整性尚有较大空间。语义复核记录保留月薪折算措辞歧义、下一步重复规则、裸引用标签等表达改进点，不把代理复核宣称为所有措辞绝对正确。

第八轮后仅增加案件状态不确定/否定词的确定性防护：如“不知道是否尚未终审”“不是未终审”不再被当作确认未终审，先补充；3条新用例覆盖。已对第八轮保存报告离线复算门槛，结果未改变，没有重写原始输出或宣称该修补又跑过一轮付费模型。
