## 已修复的问题

- 同一来源的直接/配套角色可以覆盖不同片段：合并全部有效片段，直接角色优先，不能用配套片段掩盖越界的直接片段。
- 只规范化已在选中原文中出现的交叉引用，规范化后的法律断言仍经过原有检查；未知条号仍拒绝，不自动补造缺失条文。
- 对可选意见升级为必要条件、共同财产列举范围被扩大两类已观察错误增加确定性检查；按本句引用来源检查，审核重新分配来源后再次检查。该规则是有限错误模式检查，不是通用法律逻辑证明。
- 修复重复句子的引用标签错位；按原文位置渲染，不反复替换第一次出现的位置。
- 只有部分句子失败时，修订只允许替换指定句子编号，不能修改已通过内容或新增句子；合并后的整段再次审核，仍只有一次修订机会。
- 法律回答的风险/下一步使用固定事实核实提示，避免重复推导法律条件；个案补充继续使用结构化任务。模板更通用，不声称具有个性化材料清单。
- 违约金减少回答遗漏“恶意违约一般不予支持”限制时，服务器在正文中补充选中版本的完整原文句和来源编号，不调用模型、不补充个案判断。原文必须与版本匹配；主要结论如果校验失败，不能靠这段提示放行。这是已观察限制的专门保护，不意味着所有可能例外都有确定性覆盖。
- 适用性输出只允许剔除误抄的字面 `additionalProperties:false` Schema标记，其余额外字段仍拒绝。
- 评估脚本遇到提供商401/402/403后不再发出模型请求，余题明确记为未执行，保留全部分母并将运行标为未完成。429/500不自动重试。报告仅保存HTTP状态，不记录请求头或提供商错误正文。
