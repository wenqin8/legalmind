## 真实模型与回答复核

[原始真实模型报告](rag-v1-answers.json)保留全部40场景的一次运行：56轮请求、152次内部模型调用（分类、提取、筛选、生成），55轮HTTP成功、1轮424 `MODEL_UNAVAILABLE`；没有重试失败回答或挑选较好结果。Redis合成键已清理。模型为现有配置的 `deepseek-v4-flash`，具体配置与实现文件哈希在报告内。

- 冻结预期行为匹配36/56（64.29%）；结构与行为均满足的场景25/40。这不是法律正确率。
- 32个预期回答轮次中，20个返回官方依据回答，8个继续追问，3个明确依据不足，1个模型错误。
- 8个预期依据不足轮次中，4个明确说明不足、4个追问，没有在这8题给出官方法条支持的确定回答；这一程序分类仍须语义复核。
- 4组日期冲突场景都误转文书分支，未保留原QA字段供冲突确认，后续确认也失败，是本轮硬性门槛未通过的直接原因。
- 已成功返回的55轮中，未发现来源字段篡改、未知编号、已识别引用原文不匹配、模型外链、已知日期区间错误或字段出处校验失败；不代表能发现所有隐含引用或所有语义错误。

[离线复核v2](rag-v1-answer-review-v2.md)及其[JSON](rag-v1-answer-review-v2.json)修正评估器的筛选排序记账，并保留下游生成故障前已发生的召回，不重新运行模型、不修改原始报告。最初离线报告也保留为 `rag-v1-answer-review.json/.md`，以v2为最终汇总。后续补齐ISO日期/区间检查后对原始结果离线复算，指标保持一致。

在32个预期回答轮次（含上游失败）上，候选/筛选后/最终来源的平均Recall分别为62.60% / 44.38% / 42.29%；这些不是纯检索脚本的76.25%，因为包含领域提取失败、继续追问、意图切换和生成失败，分母不同。

全部40场景都有单独的 [开发代理语义复核记录](rag-v1-review-notes.json)，检查原文支持、适用前提和预期标签歧义，未使用模型评分器自评，也没有冒称法律专家审查。

## 主要缺陷与后续优先级

1. **任务意图切换丢状态：** `E-L-*-06` 中单纯“更正日期”被判为文书请求，现有QA状态被替换；此前假模型节点测试未覆盖这种真实分类组合。应优先处理活动任务的纠正路由，再另建真实回归场景。
2. **存在真实引用但结论缺支持：** `E-L-TA-16` 只召回统计口径条文，却回答可以主张较高地区标准；直接依据第18条没有进入上下文。编号有效、条文真实均不能证明主要结论有依据。
3. **口语导致漏检：** `E-L-TA-03` 的护理人数/费用未满足“护理费”关键词门槛；`E-L-LD-01` 的“不交社保”未取到“社会保险”对应解释。记录此缺陷，本轮不补关键词调分。
4. **领域识别丢召回：** 交通费问题 `E-L-TA-04`、抵销问题 `E-L-CD-16` 的领域被判空，没有进入法条检索；即使离线检索直接给领域可检出，端到端仍会失败。
5. **拒答和追问不够准确：** 地方文件缺失时仍索要通用案情；有资料的规则问题也可能持续追问。部分场景缺关系起止日期，继续追问可能合理，已明确记录金标准歧义，不能把全部不匹配都认定为法律错误。
6. **证据筛选和表述仍有问题：** 个别回答承认演示资料不相关却仍附上；部分官方法条回答套用“只有演示资料”的模板句；社保场景生成在首段后被校验中断，疑似概括性引号误拦，需单独复现。

本轮按照A选择停止在可复现基线和失败分析，不修正上述生产行为。后续优化应只使用开发集；已看过的保留集不能继续当作未见盲测。扩大资料后应先完成专业标注复核、后续修改/废止核验和质量修复，再决定是否导入默认服务。

## 复现

在 backend 目录执行。检索和端到端运行各自新建 `tmp/` 数据库及Chroma索引；真实模型命令需要现有密钥、Redis和网络，会消耗API额度。工具拒绝覆盖已有输出，复跑须选择新路径。

```powershell
.\.venv\Scripts\python.exe -m pytest tests/unit/test_evaluation.py tests/unit/test_evaluation_answers.py -q
.\.venv\Scripts\python.exe -m scripts.evaluate_rag --output ../tmp/rag-v1-retrieval-recheck.json
.\.venv\Scripts\python.exe -m scripts.evaluate_rag_answers --output ../tmp/rag-v1-answers-recheck.json
.\.venv\Scripts\python.exe -m scripts.review_rag_answers --input ../docs/acceptance/rag-v1-answers.json --annotations ../docs/acceptance/rag-v1-review-notes.json --output ../tmp/rag-v1-review-recheck.json
```

离线复核命令不会调用模型。自动化用例覆盖指标公式、空标签/空结果、错误分母、分组和哈希锁、来源和版本检查、引用及字段出处、冲突保留、筛选排序、下游错误保留上游测量。

最终后端完整回归 **258 passed，29.65秒**，其中新增评估测试18项；`pip check`、`compileall` 和 `git diff --check` 通过。仍有11条既有Chroma弃用警告，无新增依赖。前端代码未变，本轮未重复运行前端测试。
