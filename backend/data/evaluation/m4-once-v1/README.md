# M4 新建一次性验收候选集

本版本已由[m4-once-v2](../m4-once-v2/README.md)替代。退出登录状态竞态修复后，实现指纹已改变，本包拒绝用于当前代码。查询和场景从未向待测模型提交，原文件与manifest保留；v2复用这些未执行问题并冻结新的实现指纹。

实现冻结后生成，24条新查询/24个单轮场景，四领域各6条；16条针对旧查询金标准未使用的法条，另8条覆盖事实缺失和地方资料不足。目前未运行，标签为开发代理候选，独立法律复核待完成。

这是新建、未向待测模型提交的一次性候选集。同一开发代理编写生成器，主题独立性未由专家确认，不能称为独立第三方盲测。原 rag-v1 保留集已经观察，继续保留作历史证据，不能再恢复为盲测。

`manifest.json`冻结查询、场景、实现和旧集指纹及门槛。首次真实运行前写入`observation-receipt.json`；运行失败、部分完成或基础设施故障也保留该记录，不能删除后重跑冒充首次未见验收。实现改变时原包拒绝运行，应另建版本。

真实调用须获得授权；在backend目录运行，输出使用新路径：

```powershell
.\.venv\Scripts\python.exe -m scripts.evaluate_rag_answers --allow-real-model --acceptance-package data/evaluation/m4-once-v1 --corpus-profile eval-rag-v2-209 --output ../tmp/m4-once-answers-new.json
```

只允许整包运行，不通过定向选题拼接通过答案。`complete=true`只表示执行完整，不能代替验收通过。按manifest门槛检查全部失败分母，再逐条复核正文、来源、条件、例外与标签；真实法律质量在专家标注与语义复核完成前保持未确认。标注争议须另存更正版本和理由，保留原包及原运行。

本包未使用默认60条应用库的质量成绩；实际模型配置和资料指纹记录在原始报告中。
