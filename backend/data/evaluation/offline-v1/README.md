# 离线回归记录

`recorded-extraction.json` 从第十轮合成评估中提取两次真实节点调用：一般规则字段提取成功，以及服务商故障。原始报告SHA-256、场景ID、输入、输出和错误保留，测试核对其与原始报告一致；不保存密钥、Token或真实咨询资料。

这些旧记录没有提示词哈希，仅用于显式 `allow_unverified_prompt=True` 的节点合同回放，不能验证新提示词效果。新采集的 TraceLLM 记录包含提示词哈希和原始流式分段。回放严格检查任务、输入及可用的提示词哈希，记录用尽、顺序变化或输入变化均报错，绝不转调真实模型。旧记录的模拟分段不代表原始延迟。

日常命令和验收边界见 [离线验收说明](../../../../docs/acceptance/rag-v2-offline.md)。

`validation-cases.json` 保存第八轮4条拦截及第九轮另外3条拦截的原始段落、原始报告哈希、原文快照和开发者编写的校正段落。测试逐条核对原记录，再用明确的脚本化审查结果检查一次修订、前文条件、非连续片段与错误阻断。校正段落和脚本化审查不是新模型的实际输出，不据此计算真实模型端到端分数。每个正例都有未修复内容仍被拒绝的反例。
