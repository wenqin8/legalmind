# 官方法条本地版本库

本文件描述M3默认运行清单。后续RAG-v1另增 [137条司法解释](expansion-v1/README.md)，与本清单合计197条用于隔离评估；没有修改本目录原60条或自动导入默认数据库。

首批为四部法律的 **60 条完整条文**，覆盖婚姻家庭、劳动争议、交通事故、合同纠纷的部分常见场景。它不是完整法律数据库；没有收录全部历史版本、地方规则和司法解释。不能把“覆盖四领域”理解为可以回答其中所有法律问题。

- 民法典 2020 年制定版本：32 条，2021-01-01 起施行。
- 劳动合同法 2012 年修正版本：14 条，2013-07-01 起施行。
- 劳动争议调解仲裁法 2007 年制定版本：10 条，2008-05-01 起施行。
- 道路交通安全法 2021 年修正版本：4 条，该次修改自公布之日起施行。

官方正文来自最高人民法院及北京市政府门户网站，链接保存在 `manifest.json` 和每条记录中。2026-09-18 核对正文；有效状态资料引用全国人大截至 2026-03-12 的现行有效法律目录。**核验日和状态资料截止日是两个不同字段**。回答只使用该本地快照，不能宣称每次实时核验了最新状态。部分官网直接下载失败，劳动和道路法律正文通过官方页面的网页阅读结果取得，采集方式在 manifest 中记录。

`snapshots/` 仅保留所选法律正文，不包含网站编辑文章。网页段落首尾排版空白被去除、段落用换行分隔，中文标点和条文措辞保留；`original_text` 与对应快照中的条文逐字一致，单条及快照分别记录 SHA-256。用于搜索的旧标准化 `content` 不作为原文引用，引用始终取 `verification.original_text`。

## 导入与人工更新

在 backend 目录运行：

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m scripts.import_verified_laws --check-only
.\.venv\Scripts\python.exe -m scripts.import_verified_laws
```

后续由维护者先核对官方正文、公布/生效日期、修改决定及状态资料，再更新快照、manifest 和 JSONL。`--catalog PATH` 可导入另一份已人工核验的清单；命令自身不会访问网站，也不能代替人工法律核验。

新版本必须用新的 `record_id`，不能以原 ID 改写条文。旧版本保留，更新其排他失效边界 `effective_until` 和 `amended/repealed` 状态；与新版本在同一次事务中导入。重叠的同条版本、原文哈希不符、非官方 HTTPS 链接及倒退的核验日期都会拒绝。重复导入相同清单是幂等更新。撤回不能确认的资料时，保留记录并设为 `unknown`，查询会排除。

法条候选使用独立的关系库版本过滤和现有 BM25 实现，不写入 M2 案例向量集合。最多 5 条候选，随后独立评估场景适用性。日期缺失时追问；事件早于收录版本、横跨未覆盖版本或无法确认适用条件时，不套用新法。日期过滤只是必要条件，不能替代对过渡规则及具体事项的审查。

```powershell
.\.venv\Scripts\python.exe -m scripts.evaluate_legal_retrieval --output ../docs/acceptance/legal-retrieval-evaluation.json
```

新的 20 条候选检索评估与第二周冻结查询完全独立；命中率只衡量候选召回和日期过滤，不衡量法律解释正确率。
