# RAG-v1 扩展资料

本目录新增 **137 条完整司法解释条文**，与 M3 原有 60 条合计 **197 条**。这是用户批准的四领域评估扩展语料，不是完整法律数据库。本轮将组合语料导入隔离 SQLite 验证；默认应用数据库仍保留 M3 的 60 条，未自动切换资料版本。

| 领域 | 官方司法解释 | 条数 | 所收录版本施行日期 |
| --- | --- | ---: | --- |
| 婚姻家庭 | [婚姻家庭编解释（二）](https://www.court.gov.cn/zixun/xiangqing/452771.html) | 23 | 2025-02-01 |
| 劳动争议 | [劳动争议解释（二）](https://www.court.gov.cn/zixun/xiangqing/472691.html) | 21 | 2025-09-01 |
| 合同纠纷 | [合同编通则解释](https://www.court.gov.cn/fabu/xiangqing/419382.html) | 69 | 2023-12-05 |
| 交通事故相关人身损害 | [人身损害赔偿解释（2022 修正）](https://www.court.gov.cn/zixun/xiangqing/357071.html) | 24 | 2022-05-01 |

2026-09-19 从最高人民法院官方 HTTPS 页面下载，按条文边界整理，仅保留法律正文，删除页面排版缩进、章节标题及新闻链接等网页内容；条文中的条件、例外和最后一条施行条款保留。`manifest.json` 记录官方链接、版本、公布/施行日、条数、采集方式及快照哈希；JSONL 每条另有原文哈希。未引入第三方抓取依赖。

`verified_at` 表示正文核对日期；新增记录的 `status_as_of` 只表示官方公告所明确的施行时间，不表示已完成截至 2026-09-19 的后续修改/废止排查。现有四部法律的 M3 元数据保持原样。不能用本目录声称已建立实时有效法律库。

司法解释的过渡适用不等同于单纯比较事件日和施行日。例如合同通则解释第69条还涉及民法典施行后的事实、尚未终审和再审情形。当前生产检索的日期过滤偏保守，不能完整编码这些规则；本轮保留其实现作为被测系统，不为提高分数调整规则。

关键词来自原文中的领域术语，编写于查询评估前。关键词门槛也纳入被测范围；没有根据失败查询补关键词。新增资料没有写入冻结案例 Chroma 集合。

在 backend 目录验证清单：

```powershell
.\.venv\Scripts\python.exe -m scripts.import_verified_laws --catalog data/legal/expansion-v1/verified_provisions.jsonl --check-only
```

评估脚本自动把 M3 清单和此清单一起导入 `tmp/` 下独立数据库，不需要修改 `.env`。后续若决定启用到其他运行库，可以使用现有导入器的 `--catalog` 参数；应先审阅 [评估发现](../../../../docs/acceptance/rag-v1.md)，本轮端到端质量门槛尚未通过。
