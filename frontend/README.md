# LegalMind Frontend

LegalMind 的 Vue 3 前端，包含应用入口首页、注册与登录、受保护的法律咨询工作台、公开说明页面、Pinia 状态、统一 API 客户端和 Tailwind 视觉系统。

当前可用功能是法律咨询。案例检索和文书生成在首页以“即将开放”呈现；回答仍为同步生成，尚未接入 SSE、RAG 或来源详情，界面会明确提示当前没有可核验来源，不会伪造法规和案例依据。

## 页面与交互

- `/`：公开首页。首屏可直接输入问题并进入咨询流程，也可从婚姻家庭、劳动争议、交通事故和合同纠纷四个领域开始；游客会先完成登录，再返回咨询页继续。
- `/auth`：公开的登录与注册页。桌面端保留左右分栏，移动端优先显示表单，品牌介绍位于表单下方；完整版使用边界仅在注册状态展示。
- `/guide`：公开的使用说明，介绍如何说明事实、核对依据和审慎行动，并明确当前来源检索能力尚未接入。
- `/privacy`：公开的隐私说明，解释浏览器会话、账户密码、应用数据库和配置的 AI 服务之间的数据流转。
- `/about`：公开的关于页面，集中说明项目属性、部署方式、首批支持领域和服务边界。
- `/chat`：受登录保护的咨询应用壳。点击“新建咨询”前会将已有消息归档到当前页面，桌面端可从左侧咨询记录切换，移动端可从“记录”菜单切换；每条记录均可在确认后删除。已有后端会话会同步删除归属记录，其他用户无权删除。刷新页面或退出登录仍会清除前端临时记录；后端尚未提供 Redis 持久化消息历史，模型也不会读取此前问答作为上下文。
- 其他地址：显示应用内 404 页面。

公共页面使用统一页脚链接到使用说明、隐私说明和关于页面；咨询应用壳专注于当前任务，不显示公共页脚。顶部通过 `GET /api/v1/health` 检查后端，仅展示“正在连接服务”“服务正常”或“服务暂不可用”，不向用户暴露技术版本号。

## 环境要求

- Node.js `^22.22.2`、`^24.15.0` 或 `>=26.0.0`；当前验收环境为 Node.js 24.15.0
- npm 11 或兼容版本

## 安装和启动

首次安装：

```powershell
cd frontend
npm install
```

以后可根据锁文件复现安装：

```powershell
npm ci
```

启动开发服务器：

```powershell
npm run dev
```

默认访问地址：`http://127.0.0.1:5173/`。

Vite 会把 `/api` 代理到 `http://127.0.0.1:8000`。后端暂不可用时，公开页面仍可打开，顶部会显示对应的服务状态。

注册成功后前端会自动登录。JWT 和公开用户资料只保存在 `sessionStorage`，前端不会主动持久化密码；后端保存密码哈希而非明文。应用重载时通过 `GET /api/v1/auth/me` 校验已有会话，校验失败即清理本地登录态。咨询台通过 `POST /api/v1/chat/send` 调用后端配置的 AI 服务，并通过 `DELETE /api/v1/chat/history/{session_id}` 删除已有会话归属。

## 配置

默认 API 基址为 `/api/v1`。如需覆盖，可复制 `.env.example` 为 `.env` 并修改：

```dotenv
VITE_API_BASE_URL=/api/v1
```

所有 `VITE_` 变量都会进入浏览器构建产物，因此这里不得放入 DeepSeek Key、JWT 私钥或其他秘密。DeepSeek Key 只能保存在后端本地 `.env`。

## 验证

```powershell
npm run typecheck
npm run test
npm run build
```

当前测试集包含 11 个测试文件、37 项测试，覆盖 API 客户端、认证状态、公开与受保护路由、首页入口、移动端表单顺序、服务状态文案、公开说明页、咨询记录归档/恢复/删除及咨询工作台关键交互。
